# 剧集逻辑与视觉规格（v5）

> 拍摄与改稿的硬约束。大纲与本文件冲突时，以本文件为准。

---

## 1. 剧集形态

| 项 | 规格 |
|----|------|
| 形态 | 单元剧 · 档案选集（stand alone + complex） |
| 单集时长 | **12 分钟**（片头档案页 20 秒，片尾批注+彩蛋约 50 秒） |
| 画幅 · 正片 | 1.66:1，微颗粒，三脚架与慢推为主 |
| 画幅 · 档案层 | 4:3，画内时间码、压缩块、扫描线、印章 |
| 集与集 | 正片主角互不碰面；关联只在器物、笔迹、档案层 |
| 配乐 | 日常可有极低频环境声；**异常与触碰段全程无配乐** |
| 对白 | 角色对白为零 |
| 风格母本 | 第二集（听、私藏、前人只出声）与第六集（时间磨损、最后一次看） |

六集可独立播出，也可连成一部 72 分钟的选集。

## 2. 世界硬规则（只通过画面成立，正片不解说）

### 2.1 时间轴：月城很老，静默很新

- 月城建城百余年，居民是第四代月生人。没有人「从地球来」。  
- **静默（17 年前）：** 通讯中断；官方宣告地球毁于战火；所有朝向地球的光学面加镀涂层；天幕与教材换成焦土骷髅；历法重置为 **静默历**。  
- **本季现在：** 静默 17 年 · 光学清退周。

### 2.2 代际记忆

| 年龄段 | 静默时 | 对地球的认知 |
|--------|--------|--------------|
| 17 岁以下 | 未出生 | 只知道焦土骷髅 |
| 20–30 岁 | 童年 | 残留的梦 |
| 40 岁以上 | 成年 | 清楚记得蓝色——但只记得静默之前 |

所以谎言不需要让人忘记地球 **曾经** 是蓝的，只需要让人相信它 **现在** 死了。  
本季的核心问题：**地球还在吗？我的记忆还可信吗？**

### 2.3 潮汐锁定

月球近地侧永远朝向地球。地球在天上 **不升不落**，几十年都挂在同一个位置。

推论（每一条都要在画面里成立）：

- 谎言无法靠「遮天」完成，只能给每一块朝向地球的玻璃上镀膜。  
- 观测站的望远镜 17 年不用重新对准（E06）。  
- 废廊那扇窗一旦朝着地球，就只能漆死（E04）。  
- 环线每圈都在同一段、同一个角度看见地球（E05）。  
- 六集同一周，地相一致：盈凸，约四分之三亮面。

**禁止：** 在月球背面看见地球。

### 2.4 谎言的技术是涂层

| 层级 | 看到什么 | 官方说法（只出现在画面里的标语/教材） |
|------|----------|----------------------------------------|
| 天幕 / 教材 / 宣传画 | 焦土色骷髅地球 | 「历史真实再现」 |
| 合法光学（窗膜、镜片镀膜、底漆） | 发灰的死石，或全黑 | 「防认知污染涂层」「结构加固」 |
| 涂层失效（磨穿、裂口、刮开） | 蓝白，云在慢慢走 | 事后被命名为「设备偏差」 |

- **真实地球 VFX 资产只有一套**，只在 E04（切碎）、E05（裂口）、E06（完整）以及 E04 静默元年彩蛋里出现。  
- **焦土骷髅是另一套插画资产**，几何完全不同。  
- 前四集让观众脑补地球，第五集瞥见，第六集看够再收走。

### 2.5 旧介质为什么还在，为什么本周要销毁

能远程改写的数字记录早就改完了。剩下的是改不了的东西：铜版、磁带、热敏原件、纸本、无网望远镜、逾期窗膜、未浇封的观察窗。光学清退周就是来清这些的。

## 3. 视觉语法

### 3.1 母题：圆被打开，又被关上

| 集 | 圆如何出现 | 如何被关上 |
|----|------------|------------|
| 1 | 斜光下的铜版压痕 | 熔炉 |
| 2 | 磁带盘 | 铁盒盖 |
| 3 | 过曝白圆 / 空洞 | 灌浆 |
| 4 | 30cm 观察窗 | 底漆 |
| 5 | 窗膜裂口 | 隧道 |
| 6 | 磨穿的镜片 | 关站；天幕假圆 |

### 3.2 母题：涂层

磨平的铜版、底漆、窗膜、镀膜、浆面、涂黑的编号、撕去的照片。时间不靠旁白，靠被盖住的东西重新露出来。

### 3.3 母题：手

六集高潮都是手的特写：拓、换、灌、刷、不复位、折。不用脸部表演替代。

### 3.4 调色分层

- **正片：** 冷白荧光、灰混凝土、制服灰，低饱和。  
- **档案：** 黄绿单色或劣质色彩，时间码在画面内。  
- **宣传：** 焦土橙，刻意假，边缘发光，像教材插画。  
- **真实地球：** 全片唯一允许的真蓝。无滤镜、无配乐，云要慢。  
- **清楚的是过去，模糊的是现在：** E04 元年彩蛋里的蓝必须比现在窗外清楚。

### 3.5 声音

- 本周广播同一句，音质随空间变化：`地球状态：已死亡。重复：已死亡。`  
- AI-731：击键、停顿、回车。没有人声。  
- 海浪、雨、风只存在于磁带里。月城没有天气。

### 3.6 服装

全员灰。只靠污渍区分：学生黄条、销毁员橙标、测声员耳机压痕、巡检员漆痂、司机油膜、守卫起毛的袖口。

## 4. 单集节奏（12 分钟）

| 段落 | 时间 | 画面任务 |
|------|------|----------|
| 档案冷开 | 0:00–0:20 | 封面、编号、类别 |
| 日常 | 0:20–2:30 | 重复劳动，建立「正常」 |
| 异常 | 2:30–6:00 | 一个物理事件打断重复 |
| 触碰 | 6:00–9:30 | 一个小选择。手的戏。无配乐 |
| 沉默 | 9:30–11:10 | 回到生活，人已经不同 |
| 批注+彩蛋 | 11:10–12:00 | AI 击键；器物或旧录像多给一帧 |

不用蒙太奇交代数年人生。工龄、等待、值守只用当天仍在场的磨损来呈现。

每集必须同时成立 **两种读法**（见大纲），剪辑不得替观众选边。

```
建城          百余年前。第四代月生人。
静默元年      通讯中断，宣告地球毁灭。
              朝地球的窗统一漆死（E04 她刷下第一道，001 在场）。

              表格模板 T-89-001 启用。

静默 17 年    【光学清退周】
              E01 铜版入炉          E02 磁带优先销毁
              E03 空腔第二次回填    E04 最后一次年检
              E05 窗膜逾期裂开      E06 观测站永久关停
```

前六集不回答：001 是谁、地球是否真的还在、AI-731 在对谁写隐藏行。

# 剧集逻辑与视觉规格

> 拍摄与改稿的硬约束。前六集大纲必须服从本文件，不服从的设定视为过期。

---

## 1. 剧集形态

| 项 | 规格 |
|----|------|
| 形态 | 单元剧 · 档案选集（stand alone + complex） |
| 单集时长 | **12 分钟**（含片头档案页 20 秒、片尾批注+彩蛋约 50 秒） |
| 画幅 · 正片 | 1.66:1，微颗粒，以三脚架与慢推为主 |
| 画幅 · 档案层 | 4:3，时间码，压缩块，扫描线，印章 |
| 集与集 | 正片主角互不碰面；关联只在物件、笔迹、档案层 |
| 配乐 | 日常可有极低频环境床；**异常确认与触碰全程无配乐** |

六集可独立播出，也可作为一部 72 分钟选集的上半部。

## 2. 世界硬规则（只通过画面成立，正片不解说）

### 2.1 人住在地下，天是被管理的

殖民城主体在月壤之下。公共空间的「天空」是 **天幕**：过高饱和的焦土橙、骷髅地球、标语。

真实太空只出现在四种缝隙里：

1. 被遗忘的光学设备（E01 博物馆旧观测穹顶）
2. 工业地面段（E05 末班车短暂出露）
3. 废弃气闸的外层窗/门（E04，本集不打开）
4. 近地侧隔离带的目视观测站（E06）

**禁止：** 月球背面看见地球（物理学错误，不能用「背面」当「被遗忘」的同义词）。  
E06 的站是 **近地侧边缘隔离带**，城市穹顶在地平线那头，像一座灯塔。

### 2.2 谎言的技术是「涂层」，不是「地球不在天上」

官方不需要让地球从天空消失。官方需要让你看到的地球 **永远是被处理过的**：

| 层级 | 观众看到什么 | 官方解释（只出现在画面里的标语/教材） |
|------|--------------|----------------------------------------|
| 天幕 / VR / 宣传画 | 焦土色骷髅、喷火、碎月 | 「历史真实再现」 |
| 合法光学（窗膜、目镜镀膜） | 发灰的死石 | 「辐射滤镜 / 防认知污染涂层」 |
| 非法/失效光学 | 蓝白，云带缓动 | 被事后命名为「设备偏差」 |

**同一颗地球 VFX 资产**贯穿 E01 / E05 / E06，只改裁切与滤镜。  
**焦土骷髅是另一套插画资产**，几何完全不同，观众可直觉区分「照片」与「宣传画」。

### 2.3 「窗口期」是什么（内部定义，正片不念出来）

移民历元年起，近地侧某条废弃气闸在每年同一日的同一时辰，会因轨道几何让地球升到舱门视野中央。那几小时叫窗口期。

T-89-001 在元年窗口按住一个女人的手：还不是时候。  
观测站也从那一日起，用统一格式写「今日无异常」。

本季「现在」= **移民历 17 年 · 同一宣传周**（光学清退周 / 「地球已死亡」强化宣导）。六集发生在这一周的不同岗位，世界状态一致。

### 2.4 编号 T-89 是观察案卷，不是身份证

T-89 是「地球认知偏差」观察序列。角色工牌上可以有职务编号；T-89-xxx 主要印在档案脊、处分页、批注栏。

正片不解释缩写。观众只反复看见这个字头。

| 编号 | 样本 | 与 001 的关系（内部） |
|------|------|----------------------|
| T-89-001 | 未露面者 | 序列第一号 |
| T-89-011 | 女孩的母亲 | 已处理 |
| T-89-023 | 女孩 | 因母亲被标记 |
| T-89-058 | 磁带管理员 | 销毁链上的执行者 |
| T-89-091 | 矿工 | 现场发现被回填的结构 |
| T-89-106 | 老年妇女 | 窗口期的等待者 |
| T-89-118 | 司机 | 地面段目击 |
| T-89-143 | 老守卫 | 17 年目视值守 |

### 2.5 模拟介质还活着，是因为数码已经死绝

可远程擦除的东西早就被擦了。本周正在清退的是磁带、纸质日志、无网望远镜——不能被一键改写的东西。

所以：F-99 优先销毁、矿区十年前的纸本被红线、观测站被关、博物馆旧穹顶被列为未开放。

### 2.6 微小动作必须在物理上成立

| 禁止 | 原因 | 改为 |
|------|------|------|
| 真空竖井里脱外套盖尸体 | 人会死亡 | 进入旧着陆舱残腔；用作业包里的隔热毯覆盖 |
| 光学望远镜剪电线就没图像 | 纯光学不靠电 | 电控穹顶快门 / 镜盖合上，圆形视野被掐灭 |
| 老人穿着宇航服穿过市区 | 必被举报，也破坏「微小」 | 便服走到气闸，在闸室内穿衣 |
| 从「月球背面」走回城市 | 距离与地球不可见 | 近地侧脊道安全索，穹顶在视线尽头 |
| 手动望远镜「今天第一次看见蓝」却值守了 17 年 | 动机不成立 | 17 年透过镀膜看灰石；镀膜磨穿的当天与广播对撞 |

## 3. 视觉语法（系列可识别性）

### 3.1 母题：圆被打开，又被关上

| 集 | 圆如何出现 | 圆如何被处置 |
|----|------------|--------------|
| 1 | 穹顶目镜里的地球 | 快门虹膜合上 |
| 2 | 磁带盘旋转 | 铁盒盖合上 |
| 3 | 臂章上褪色的地球刺绣 | 夹进日志合上 |
| 4 | 手动开启按钮（圆） | 手按上去，不按下 |
| 5 | 车窗里的地球 | 隧道吞掉 |
| 6 | 磨穿后的目镜 | 他带走纸条；城市只剩天幕假圆 |

摄影：目镜、隧道、按钮、地球、日历装订孔、公章，优先用正圆构图。

### 3.2 母题：涂层 / 覆盖 / 回填

墙漆盖涂鸦、编号涂黑、窗膜起皮、目镜镀膜磨穿、矿坑回填、照片撕去。  
**时间不靠旁白，靠「被盖住的东西重新露出来」。**

### 3.3 母题：手

六集高潮都是手的特写，禁止用脸部表演替代：

藏、换、盖、按、不复位、折。

### 3.4 两套影像，不许混用调色

- **正片：** 冷白荧光、灰混凝土、制服灰。饱和度低。
- **档案：** 黄绿单色或劣质色彩，时间码在画面内（不是后期花字）。
- **合法宣传：** 焦土橙，刻意假、边缘发光、像教材插画。
- **非法光学：** 唯一允许出现的真实蓝。无滤镜、无配乐、云要慢。

### 3.5 声音

- 公共广播同一句，本周反复出现，音质随空间变：`地球状态：已死亡。重复：已死亡。`
- AI-731：击键，停顿，回车。没有人声。
- 海浪只存在于磁带。月面上任何「水声」都是违规记忆。

### 3.6 服装

全员灰。只靠污渍和袖章区分职业：学生袖口黄条、销毁员橙标签、矿工粉尘、市民无袖章、司机手套油膜、守卫旧毛边。

## 4. 单集镜头节奏（12 分钟）

| 段落 | 时间 | 画面任务 |
|------|------|----------|
| 档案冷开 | 0:00–0:20 | 封面、编号、类别。建立「被调阅」 |
| 日常 | 0:20–2:30 | 重复劳动。让观众知道「正常」长什么样 |
| 异常 | 2:30–6:00 | 一个物理事件打断重复（卡住、起皮、磨穿、闪帧） |
| 触碰 | 6:00–9:30 | 一个小选择。手的戏。无配乐 |
| 沉默 | 9:30–11:10 | 回到生活，人已经不同。仍无解释 |
| 批注+彩蛋 | 11:10–12:00 | AI 击键；物件或旧录像多给一帧 |

禁止用蒙太奇交代数年人生。工龄、等待、值守只用 **当天仍在场的磨损** 完成。

## 6. 物件流转（只在彩蛋层闭合）

```
母亲的画 ──► 女孩胸口（不离开 E01）
F-99 磁带 ──► 铁盒（E02）
臂章 +「重审」日志 ──► 次日销毁车（E03 彩蛋，同一辆 E02 的车）
航线图 ──► 手提箱（E04，AI 看见它，人不用它）
隧道刻字 ──► 新刻字「我看见了」（E05 彩蛋）
「地球还在」纸条 ──► 守卫口袋（E06，系统未收录）
```

正片零对面。E03 彩蛋只出 **橙标签手套 + E02 销毁车轮子**，不出管理员正脸对矿工。

## 7. 口头声源配额

角色出口语全季仍 ≤ 10 句。  
广播、磁带、笔录算声源，不算角色对白。  
任何一句对白必须同时完成两件事：推动当集因果，并留下可被档案引用的「不当言论」。

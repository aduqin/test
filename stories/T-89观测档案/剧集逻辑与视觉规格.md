# 剧集逻辑与视觉规格

> 拍摄与改稿的硬约束。前六集大纲必须服从本文件，不服从的设定视为过期。

---

## 1. 剧集形态

| 项 | 规格 |
|----|------|
| 形态 | 单元剧 · 档案选集（stand alone + complex） |
| 单集时长 | **12 分钟**（含片头档案页 20 秒、片尾批注+彩蛋约 50 秒） |
| 画幅 · 正片 | 1.66:1，微颗粒，以三脚架与慢推为主 |
| 画幅 · 档案层 | 4:3，时间码，压缩块，扫描线，印章 |
| 集与集 | 正片主角互不碰面；关联只在物件、笔迹、档案层 |
| 配乐 | 日常可有极低频环境床；**异常确认与触碰全程无配乐** |

六集可独立播出，也可作为一部 72 分钟选集的上半部。

---

## 2. 世界硬规则（只通过画面成立，正片不解说）

### 2.1 人住在地下，天是被管理的

殖民城主体在月壤之下。公共空间的「天空」是 **天幕**：过高饱和的焦土橙、骷髅地球、标语。

真实太空只出现在三种缝隙里（前几集故意不给全）：

1. 废廊观察窗，常年被底漆封死（E04，切框、看不清）
2. 工业地面段车窗（E05，只从窗膜裂口露出一条）
3. 近地侧隔离带的目视观测站（E06，目镜里完整）

E01 不给天空：圆只存在于斜光压痕。E02 不给天空：海只存在于磁带。E03 不给天空：只有过曝白圆。

**禁止：** 月球背面看见地球（物理学错误，不能用「背面」当「被遗忘」的同义词）。  
E06 的站是 **近地侧边缘隔离带**，城市穹顶在地平线那头，像一座灯塔。

### 2.2 谎言的技术是「涂层」，不是「地球不在天上」

官方不需要让地球从天空消失。官方需要让你看到的地球 **永远是被处理过的**：

| 层级 | 观众看到什么 | 官方解释（只出现在画面里的标语/教材） |
|------|--------------|----------------------------------------|
| 天幕 / VR / 宣传画 | 焦土色骷髅、喷火、碎月 | 「历史真实再现」 |
| 合法光学（窗膜、目镜镀膜） | 发灰的死石 | 「辐射滤镜 / 防认知污染涂层」 |
| 非法/失效光学 | 蓝白，云带缓动 | 被事后命名为「设备偏差」 |

**同一颗地球 VFX 资产**只在 E04（切碎）/ E05（裂口）/ E06（目镜）出现，裁切越来越完整。  
**焦土骷髅是另一套插画资产**（教材、天幕），几何完全不同。

前四集的任务是让观众 **脑补** 地球；第五集瞥见；第六集看够再收走。

### 2.3 「窗口」是什么（内部定义，正片不念出来）

移民历元年，近地侧废廊一扇 30cm 观察窗被令封闭。T-89-001 在场，让当时的女工刷上第一道底漆：「还不是时候。」  
观测站也从那一日起写「今日无异常」。  
此后每年同一日，由同一名女工（后来的巡检员）刮开年检、再封上。第十七年她多看了 4 分 12 秒。

本季「现在」= **移民历 17 年 · 光学清退周**。六集同一周不同岗位。

### 2.4 编号 T-89 是观察案卷，不是身份证

T-89 是「地球认知偏差」观察序列。角色工牌上可以有职务编号；T-89-xxx 主要印在档案脊、处分页、批注栏。

正片不解释缩写。观众只反复看见这个字头。

| 编号 | 样本 | 与 001 的关系（内部） |
|------|------|----------------------|
| T-89-001 | 未露面者 | 序列第一号：磁带遗言 / 元年漆桶 / 表格页脚 / 建站空白 |
| T-89-011 | 女孩的母亲 | 印版技工，已处理 |
| T-89-023 | 女孩 | 教材净化工坊；因母亲被标记 |
| T-89-058 | 磁带管理员 | 销毁链 |
| T-89-091 | 测声/灌浆员 | 十年后再回填同一空腔 |
| T-89-106 | 密封巡检员 | 元年刷上底漆的人，第 17 次年检 |
| T-89-118 | 司机 | 窗膜逾期未换 |
| T-89-143 | 老守卫 | 17 年目视值守 |

### 2.5 模拟介质还活着，是因为数码已经死绝

可远程擦除的早已被擦。本周清退：铜版、磁带、热敏原件、无网望远镜、逾期窗膜。

### 2.6 微小动作必须在物理上成立

| 禁止 | 原因 |
|------|------|
| 让角色「看见完整真相」作为第一集高潮 | 变成证明题，余味消失 |
| 真空竖井展示遗体、可读遗言 | 探险片，吃掉联想 |
| 宇航服穿街、气闸出发 | 动作升级成逃亡 |
| 隧道涂鸦写出答案 | 「蓝的是真的」会把想象钉死 |
| 月球背面看地球 | 物理错误 |
| 17 年每天看见蓝却写无异常 | 动机不成立：镀膜后是灰石，磨穿当天才蓝 |

## 3. 视觉语法（系列可识别性）

### 3.1 母题：圆被打开，又被关上

| 集 | 圆如何出现 | 圆如何被处置 |
|----|------------|--------------|
| 1 | 斜光下拓纸上的圆 | 熔炉吃掉铜版 |
| 2 | 磁带盘 | 铁盒盖 |
| 3 | 过曝白圆 / 空洞 | 灌浆抹平 |
| 4 | 30cm 观察窗 | 底漆刷黑 |
| 5 | 窗膜裂口 | 隧道吞掉 |
| 6 | 磨穿的目镜 | 关站；天幕假圆 |

摄影：目镜、隧道、按钮、地球、日历装订孔、公章，优先用正圆构图。

### 3.2 母题：涂层 / 覆盖 / 回填

打磨铜版、盒盖、灌浆、底漆、窗膜、镀膜、涂黑编号、撕去的照片。  
**时间不靠旁白，靠「被盖住的东西重新露出来」。**

### 3.3 母题：手

六集高潮都是手的特写：拓、换、灌、刷、不复位、折。禁止用脸部表演替代。

### 3.4 两套影像，不许混用调色

- **正片：** 冷白荧光、灰混凝土、制服灰。饱和度低。
- **档案：** 黄绿单色或劣质色彩，时间码在画面内（不是后期花字）。
- **合法宣传：** 焦土橙，刻意假、边缘发光、像教材插画。
- **非法光学：** 唯一允许出现的真实蓝。无滤镜、无配乐、云要慢。

### 3.5 声音

- 公共广播同一句，本周反复出现，音质随空间变：`地球状态：已死亡。重复：已死亡。`
- AI-731：击键，停顿，回车。没有人声。
- 海浪只存在于磁带。月面上任何「水声」都是违规记忆。

### 3.6 服装

全员灰。只靠污渍区分：学生黄条、销毁员橙标、测声员耳机压痕、巡检员漆痂、司机油膜、守卫毛边。

## 4. 单集镜头节奏（12 分钟）

| 段落 | 时间 | 画面任务 |
|------|------|----------|
| 档案冷开 | 0:00–0:20 | 封面、编号、类别。建立「被调阅」 |
| 日常 | 0:20–2:30 | 重复劳动。让观众知道「正常」长什么样 |
| 异常 | 2:30–6:00 | 一个物理事件打断重复（卡住、起皮、磨穿、闪帧） |
| 触碰 | 6:00–9:30 | 一个小选择。手的戏。无配乐 |
| 沉默 | 9:30–11:10 | 回到生活，人已经不同。仍无解释 |
| 批注+彩蛋 | 11:10–12:00 | AI 击键；物件或旧录像多给一帧 |

禁止用蒙太奇交代数年人生。工龄、等待、值守只用 **当天仍在场的磨损** 完成。

## 5. 时间线（内部，供制片与续集）

```
移民历元年      观察窗奉令封闭。001 在场。观测站开始「无异常」。
移民历 7 年     同坐标空腔第一次回填（表格模板页脚 001）
移民历 17 年    【光学清退周】
                E01 铜版入炉    E02 磁带优先销毁
                E03 空腔第二次回填    E04 第 17 次封窗年检
                E05 窗膜逾期起皮      E06 观测站永久关停
```

前六集结束后仍不回答：001 是谁、地球文明是否还在、AI-731 在为谁写隐藏备注。

## 6. 物件流转（只在彩蛋层闭合）

```
拓纸 ──► 女孩胸口（系统扫描件几乎空白）
F-99 ──► 铁盒（系统以为已销毁）
热敏白圆 ──► 午餐铁盒（电子档写着玄武岩；销毁车收到空袋）
观察窗 ──► 再刷上（多看的 4:12 写进阈值）
黑匣子多出两段静 ──► 可裁切，未裁（光标停住）
「地球还在」──► 守卫口袋（系统只看到已退休）
```

正片零对面。E03 彩蛋只出橙手套与 E02 同一辆销毁车。

## 7. 口头声源配额

角色出口语可以为零。本版前六集默认 **零对白**。  
声音交给：砂纸、海浪、回波、刷子、轨缝、广播、击键。  
闪回气声「还不是时候」可听可不听，不作字幕。

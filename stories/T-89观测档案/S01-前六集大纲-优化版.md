## 第一集：《蓝色蜡笔》

| 项 | 内容 |
|----|------|
| 档案 | T-89-023 · 教育系统·认知矫正案例 |
| 主角 | 女孩，9 岁。学生袖口黄条。工牌角有不易察觉的 T-89 色点（同宿舍孩子没有） |
| 核心动作 | 把母亲的画从床垫下转移到胸口内袋 |
| 情绪 / 色 | 愤怒 · 冷白灰 |
| 场景 | 宿舍 → 战争创伤博物馆（VR 大厅 / 未开放观测穹顶）→ 宿舍夜 |
| 蓝色 | 第一级：被快门夺走的窥视 |

### 本集因果（必须成立）

她不是「碰巧看到真相」。博物馆把旧观测穹顶标成未开放，是因为快门机构卡在微开，会漏光。她因 VR 里的地球「形状不对」才去找能核对的东西。系统用断电合上快门，再用笔录把蓝写成偏差。她把画贴到胸口：从此证据只离心脏最近。

### 分场

**冷开 0:00–0:20（档案）**  
4:3 封面。编号打印机一行行跳出。类别章砸下。没有音乐。

**1. 宿舍晨 0:20–2:30（日常）**  
1.66 正片。冷白灯。一排完全相同的床。她掀床垫一角：揉皱的地球素描，蓝绿色圆，边缘铅笔字「我猜，地球长这样」。蜡笔不是画具，是夹在画里的遗物。她看一眼，垫回去。  
墙面一块涂料色差——覆盖过的涂鸦，边缘像圆。她从它旁边走过，不碰。  
广播在走廊很远：`地球状态：已死亡。` 孩子们无人抬头。

**2. 博物馆 VR 2:30–4:20（异常开始）**  
VR 大厅：焦土橙、骷髅地球、火焰击碎月球。声音过大，同学闭眼。她不闭。头盔反光里，她的眼睛睁着。  
无声口型，极轻：「不对。」  
（不是哲学判断——是形状判断。宣传画的地球没有云的运动，只有爆炸。）

**3. 未开放穹顶 4:20–6:00（异常完成）**  
人流去下一展厅。她借厕所方向走进铁门「未开放·设备检修」。门虚掩，不是英雄潜入，是被遗忘。  
圆形穹顶，积灰。目镜高度刚好够她垫脚。她把眼贴上去。

**目镜主观（正圆遮罩，无配乐）：** 蓝绿，白云极慢。同一颗地球资产的第一次无滤镜。她的泪掉在目镜橡胶上，留下深色月牙。  
气声：「妈妈……你是对的。」

**4. 快门 6:00–7:40（触碰被中断）**  
侧翼红灯：穹顶功耗/位移报警。不是老师心灵感应。  
老师与两名馆内警卫进入。一人拍控制台 **「紧急闭合」**。  
画面：快门如虹膜收缩，蓝圆变成一条缝，灭。她的瞳孔里还留着残像。  
她被拖走时仍回头看已经合上的圆。

**5. 宿舍夜 7:40–11:10（触碰完成 + 沉默）**  
她坐在床沿。蓝色蜡笔在手里转，**不画**。  
掀开床垫，取出那张画。这一次不放回去。她把画展平，塞进校服胸口内袋，用掌心压实，贴住。  
镜头只推眼睛：不是困惑，是愤怒。  
蜡笔搁在桌上，完整，没用过。

**笔录 11:10–11:35（档案）**  
4:3 固定机位。老师不看镜头看提词器下方的表格：「设备年久失修，成像有偏差。」时间码跳帧。画质劣于正片。

**彩蛋 11:35–11:50**  
翻页：T-89-011「不可挽回的认知偏差·已处理」。照片撕去，残留蜡笔蓝粉。关联编号栏涂黑，透出 `T-89-001`。

**AI-731 11:50–12:00**  
击键：「建议：清除该符号。」光标停在「符号」后一拍，回车。标准，无情绪。

### 拍摄要点

- 地球只存在于目镜圆内，禁止切大外景。  
- 快门闭合是本集「圆被关上」的主特效，必须听得到金属摩擦。  
- 核心动作是转移藏匿点，不是「又看了一遍画」。

## 第二集：《磁带管理员》

| 项 | 内容 |
|----|------|
| 档案 | T-89-058 · 数据销毁·执行人员行为评估 |
| 主角 | 男，25 岁。橙标签挂绳，销毁员 |
| 核心动作 | 用空壳调包，把 F-99 藏进铁盒 |
| 情绪 / 色 | 好奇/恐惧 · 暗黄+冷白 |
| 场景 | 地下销毁库 → 独居公寓 |
| 蓝色 | 本集不出现地球画面；海浪是「蓝」的声音替代 |

### 本集因果

模拟带本周优先清退。橙标=系统判定为「环境噪音、可延后」。F-99 被红笔圈出，说明有人/有程序发现这盘不是噪音。他早已私藏三盘橙标（雨、风、城市），所以公寓里**已经有**播放器。调包让系统记录「F-99 已销毁」。他听见海——月城没有海。B 面四碎片把他从收藏噪音推进收藏遗言。

### 分场

**冷开** 销毁任务单扫描。红圈：「F-99 优先销毁」。

**1. 库房 0:20–2:30（日常）**  
他推车。动作熟：扫码、入箱、送焚毁口。摄像头在死角上方缓慢扫过。灯的嗡鸣稳定。他经过一排橙标磁带，手的习惯性摩挲——这些他碰过很多次。

**2. F-99 2:30–5:30（异常）**  
目标架。一盘外壳与其它相同，多一张不属归档系统的手写便签：「听听看。」字迹工整、微右倾。  
他停住。摄像头转到另一侧。他从车下层取出一盘**已扫描过的空壳**（标签被他提前用库内打印机仿制，边角新于原带——特写一次即可，不解释）。F-99 进外套内袋。空壳入车。扫码成功音。系统认为它死了。

**3. 公寓 5:30–9:30（触碰）**  
锁门。关灯。只留播放器的红点。播放器本来就在——与铁盒是一套犯罪工具，不是今晚新买。  
A 面：海浪。持续、厚、有呼吸。他坐在床边，第一次出现不会处理的表情。手不知道放哪。  
B 面，四截可辨，中间全是磁粉噪声：

1. 「如果你听到这个……」  
2. 「这盘带子是火种……」  
3. 「去听海的声音……」  
4. 「我叫……T-89-001……」

他倒带。再听第四截。停。

床底铁盒。锈。里面三盘橙标：雨、风、城市噪音。F-99 放进去。盒盖合上——本集的圆被关上。

**4. 沉默 9:30–11:10**  
他躺着。铁盒在床下。手指在自己的拇指侧反复摩挲，动作与摩挲磁带盒同一个。窗外没有海。

**彩蛋** 评估表附页：B 面第四截波形尖峰。一行旁注被涂改，原词只剩残画。

**AI-731** 「建议：加强对其活动的观察频率。」  
「频率」二字有一次删除重打。残留词影像「保」。

### 拍摄要点

- 调包必须在一个镜头里用身体挡住摄像头，让观众看懂「系统在看，但没看见」。  
- 海浪是本集最大的「特效」，不要配画面闪回海岸。  
- 铁盒磨损=他干这件事已经很久；F-99 是质变不是起点。

## 第三集：《矿工》

| 项 | 内容 |
|----|------|
| 档案 | T-89-091 · 资源开采·深度作业异常记录 |
| 主角 | 男，45 岁。粉尘、虎口旧伤 |
| 核心动作 | 臂章夹进十年前的纸本，封面写「重审」 |
| 情绪 / 色 | 困惑 · 灰褐 |
| 场景 | 钻探舱 → 竖井底旧着陆舱残腔 → 地面报告台 → 夜间矿区纸本室 |
| 蓝色 | 只存在于臂章褪色刺绣，不出现天空 |

### 本集因果

十年前回填的是「不明结构」。本周钻头在同一坐标卡住——回填层与原生月壤颜色不同（画面能读）。他按规程下井，打开的不是矿脉，是 2067 地球着陆舱的舱口。舱内仍是密封残腔，可掀面罩。他可以盖毯、撕臂章。公开电子表必须写「未发现异常」，否则停工。夜间纸本室是已停用但仍未粉碎的旧系统——与本周「清退模拟介质」同一政策。他不把纸本带走，只把证据塞回去等被收走。次日，E02 那辆销毁车按期来收。

### 分场

**冷开** 坐标页、深度 80 米、钻压报警。

**1. 钻探 0:20–2:20（日常）**  
重复：推进、震动、他的身体随钻机抖。铭牌年份特写。帽檐油圈。井壁刻度被刮过很多次。工龄全部用物证，不溶年龄。

**2. 卡住 → 残腔 2:20–6:20（异常）**  
回填层：颜色错。他下井。金属板。擦开月尘：「科考队……2067……」数字是地球历，与移民历表格并置即产生违和，无需台词。  
撬开：着陆舱舱口。入内。一具旧式宇航服遗体。胸牌：「地球科考队·王征·2067」。  
内衬记号笔，月尘吞字，可读残句：「我们不是来……」其余进褶皱。  
臂章：灰底，地球刺绣只剩一圈蓝绿线。他用指甲扣下，入内袋。  
作业包抽出标准隔热毯，盖住胸牌。盖，不是悼词。合上面罩。出舱。封回金属板——他知道封不住。

**3. 地面报告 6:20–7:20**  
电子表「异常情况」：他写下「未发现异常。」提交音。钻机复工指令亮起，被他关掉屏幕。

**4. 纸本室夜 7:20–9:40（触碰）**  
同一行政廊，灯只开一排。他找出十年前同坐标纸本。原始字：「发现不明结构，建议考古评估」。红线。章：「已回填」。处理人栏淡墨尾号 `001`。  
臂章夹进那一页。封面空白处写「重审」。放回原位。关门。

**5. 沉默 9:40–11:10**  
他在更衣室摘帽，挂回自己的钩。正常打卡离开。粉尘脚印到门口为止。不做离职宣言。

**彩蛋 11:10–11:45**  
次日。一辆销毁车轮特写——与 E02 同一伤痕。橙标签手套推门。抽出那本纸，翻到臂章。停一拍。入车。不露面。

**AI-731** 「行为评估：异常。」附：覆盖遗体=非必要接触 · 情绪量化条首次出现。

### 拍摄要点

- 舱内用实体布景，不要大竖井威亚。  
- 「我们不是来……」必须被布料挡住，剪辑不允许补全。  
- 彩蛋只认车与手套，完成第二层拼图即可。

## 第四集：《窗口期》

| 项 | 内容 |
|----|------|
| 档案 | T-89-106 · 民生系统·信用惩戒记录 |
| 主角 | 女，65 岁。无袖章市民 |
| 核心动作 | 在外层按钮上放手，不按下 |
| 情绪 / 色 | 等待 · 灰蓝 |
| 场景 | 家 → 广场天幕 → 市民中心窗口 → 家 → 边缘气闸 |
| 蓝色 | 天幕插画闪一帧真蓝（假天空的裂缝），随即被纠正 |

### 本集因果

日历红圈=本年窗口日。她每年这一天检查航线图和宇航服，去气闸，等一个 17 年未再出现的人。本周宣传片在天幕上播焦土地球；播放中插画资产加载错误，**闪过一帧无滤镜地球**（与 E01/E05/E06 同一资产）。她说「画得太假了」——被广场拾音举发。配额扣 12%，再一次即永久取消。她仍去气闸：在惩戒升级后把仪式走完，是本集的微小冒犯。宇航服不穿过市区。地图被带去却不展开——所以 AI 看见「未对地图采取行动」。

### 分场

**冷开** 信用档案。氧气卡余额条。

**1. 家 0:20–2:20（日常）**  
撕日历。地上纸堆到踝。墙上一排旧钉眼。衣柜宇航服落灰，密封条有反复折痕。  
手提箱：旧航线图，月面边缘到一扇闸，旁有手绘小圆（地球高度）。她只确认还在，折好。工牌在箱盖夹层：年轻的她，「气闸维护」。过期。

**2. 广场 2:20–4:40（异常）**  
天幕焦土地球，标「已死亡」。广播同句。画面忽然一帧蓝白云带——像放错了文件。弹回骷髅。路人无反应。  
她停。低声：「画得太假了。」  
路人侧目。她已经走了。拾音杆的红点在画面边角亮过。

**3. 窗口 4:40–6:00**  
屏幕：「本月配额：-12%。公共场所不当言论。」工作人员推回氧气卡：「再有一次，永久取消。」  
她接过。无争辩。转身。卡上条变短，是纯视觉惩罚。

**4. 再回家 → 气闸 6:00–9:40（触碰）**  
日历红圈。检查接口、搭扣、密封条。便服出门，手提箱。城市边缘。废弃气闸。刷过期工牌：阅读器黄灯「维护通道·过期」。门仍开——官僚漏洞，不是黑客。  
闸室内穿衣。这一段用装配的声音代替对白：卡扣、氧检、一声合格蜂鸣。  
外层门。圆按钮「手动开启」。她的手上去。手指抖。不按。闭眼。等。舱内计时器走完窗口标注的时段（用一个旧的机械表，不用字幕解释）。她收回手。

**5. 沉默 9:40–11:10**  
她坐在内闸门槛上，面罩搁在膝。不哭。把航线图放回箱底。原路返回的第一级门在她身后合上。圆又关上。

**彩蛋** 同一机位，17 年前。年轻的她，同一按钮。一个面部始终出焦的男人按住她的手：「还不是时候。」袖口布条一闪 `T-89-001`。她收回手。  
切回现在：同一机位，只有她。时间码年份差 17。

**AI-731** 「样本未对地图采取任何行动。仅观察。」

### 拍摄要点

- 17 年前后必须 **机位、焦距、按钮特写完全可叠化**。这是本集也是前六集的视觉锚。  
- 天幕闪帧不超过 4 格，让一部分观众怀疑自己看错。  
- 穿衣在闸室，城市街道上她只是一个提箱的老人。

## 第五集：《夜班》

| 项 | 内容 |
|----|------|
| 档案 | T-89-118 · 公共运输·末班车异常记录 |
| 主角 | 男，45 岁。手套有油膜 |
| 核心动作 | 多开两圈，交班不复位计数器 |
| 情绪 / 色 | 觉醒 · 冷黑+蓝白 |
| 场景 | 地下驾驶室 → 地面段 → 服务隧道盲区 → 车库坡道 |
| 蓝色 | 第二级：窗膜裂缝里的直视，被隧道吞掉 |

### 本集因果

司机每天经过地面段 187 次，看见的是窗膜滤镜里的灰色死石，所以他可以「不看」。本周光学清退，膜老化大面积起皮——他不是突然勇敢，是物理上无法再假装那是灰的。他在规定外的盲区停车，因为只有停在那块护板前才能看见给后来者的刻字（字不在日常时速的视野里）。多开两圈=再看两次未滤镜的地球。不复位=让黑匣子替他记住。车库坡道有一条通向真实天空的役用缝，他第一次在役用缝下站定。

### 分场

**冷开** 排班表。黑匣子封面。今日班次：187。

**1. 机械驾驶 0:20–2:20（日常）**

## 第六集：《17年》

### 本集因果

站将关，因为无网目视不能被远程改写。合法目镜有「防认知污染镀膜」，17 年他每天看见的是灰石，所以每天可以诚实写「无异常」（在官方语义里）。关站日他按清单做最后校准，指腹摸到镀膜在常用坐标磨穿——透明。广播同时说已死亡。他无法再写无异常。纸条不贴墙：贴墙是给系统看的格式；入口袋是第一次把记录变成私有。他沿安全索走回城市（距离可拍），在天幕下抬头——假圆对着真记忆。

### 分场

**冷开** 永久关停指令。封存表。建站：移民历元年。第一任守卫：空白。

**1. 拔线 0:20–2:30（日常）**  
一台台拔掉联网设备。打勾。动作熟练得像另一种撕日历。墙：17 年「今日无异常」，上黄下白。角落实是一沓撕下的旧日历（与 E04 同款纸，不点破）。

**2. 最后校准 2:30–6:20（异常）**  
只剩手动望远镜。扬声器：`地球状态：已死亡。重复：已死亡。`  
他坐。调焦。指腹拂目镜：常用位置镀膜磨穿，一圈玻璃露底。  
正圆主观：蓝白，云，旋转。同一资产，最干净的一次。他看很久。广播不停。无配乐。

**3. 纸条 6:20–9:20（触碰）**  
白纸。写：「今日有异常：地球还在。」停笔。看墙上的格式。不贴。折成小块，进胸前口袋。掌心按住——与 E01 女孩同一位置的手。  
关最后一盏灯。出门。门外「永久关闭」红灯。脊道。安全索。远处城市穹顶像一颗假的亮点。半路回头：观测站只剩黑块。

**4. 安检与广场 9:20–11:10（沉默）**  
刷卡：「T-89-143·已退休·权限清除·欢迎回家。」新发的民用氧气卡，条很满，像奖赏。  
广场=E04 同一空间。天幕骷髅地球。人群议论广播。他站在边缘抬头。不说话。假圆在他眼睛里。

**彩蛋** 目镜特写：镀膜磨光的圆。后面没有眼睛了。玻璃对着空房间。17 年的手汗包浆仍在边缘。

**AI-731** 「样本已脱离岗位。后续安置：普通居民区。」  
击键停。隐藏行，字号细一号：「17年。足够了。」

### 拍摄要点

- 观测站外景用「脊+索+远穹顶」，不要大基地。  
- 目镜磨穿用实体镀膜道具，与 E05 窗膜是同一物理观念。  
- 口袋与 E01 胸口形成系列收束，不需要对白互指。

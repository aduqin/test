# 《T-89观测档案》第一季·前六集（风格改写版）

> 风格锚点：第二集《磁带管理员》、第六集《17年》。  
> 参考温度：《爱、死亡和机器人》——单集一个职业、一件器物、一次不合规；情节让位给余味。  
> 博物馆望远镜、竖井遗体、穿街宇航服、隧道涂鸦、广场举报：**已废弃，不再沿用。**

## 这版在写什么

第二集让人记住的不是「反派体制」，是 **黑房间里一盘不该存在的海**。  
第六集让人记住的不是「关站」，是 **17 年把镀膜磨穿的那一圈玻璃**。

其余各集按这个标准重写：少事件，多残留；真相当场不给全，留给观众自己补完。

| 集 | 标题 | 感官 | 带走的那一帧 |
|----|------|------|----------------|
| 1 | 蓝色蜡笔 | 触 | 斜光下纸上才出现的圆 |
| 2 | 磁带管理员 | 听 | 铁盒盖上，海还在耳机里 |
| 3 | 回填 | 听→埋 | 浆面最后一颗气泡消失 |
| 4 | 底漆 | 窥 | 湿漆里她自己的脸 |
| 5 | 第187次 | 重复 | 复位键没按，手套粘着一条窗膜 |
| 6 | 17年 | 看 | 没人再看的目镜 |

六集仍是同一座月城、同一个清退周、同一套涂层谎言。正片互不碰面。

## 第一集：《蓝色蜡笔》

| 项 | 内容 |
|----|------|
| 档案 | T-89-023 · 教育系统·教材净化劳动 |
| 主角 | 女孩，9 岁。袖口黄条。工牌角一点 T-89 色点 |
| 核心动作 | 用母亲的蓝蜡笔拓下一张即将被熔掉的旧印版，把只有斜光才看得见的圆塞进胸口 |
| 本集不给 | 望远镜、博物馆、真地球画面 |
| 余味 | 蓝可能从来只存在于压痕里 |

### 为什么改

上一版让她「看见」了。看见就会变成证明题。第二集从不证明海在地球上——它只让人听见。  
本集同样：官方正在把旧地球从铜版上磨掉。她没有看到行星，只偷走一层皮肤。

### 因果

有偏差记录的孩子被安排进教材净化工坊，用砂纸打磨旧印刷铜版，直到表面只剩金属，再送熔炉。新教材只准焦土橙。她母亲留下的蓝色蜡笔不是画具，是旧油墨的颜色标本。她在一块版上磨得太轻，斜光里现出一个圆。监督只扫平面，看不见。下班前铜版入炉。她在炉前用蜡笔拓纸。纸看起来几乎是空白。夜里她斜过台灯——圆出现，一偏又消失。她把这张「空纸」贴进胸口。

### 分场（12'）

**冷开** 档案封面。类别：教材净化劳动。附件：工位记录，全是砂纸。

**日常 0:20–2:40**  
工坊。一排孩子。铜版、砂、灰。墙上贴焦土地球教材样张，橙得发假。她的动作已经熟——这不是第一天。砂纸的声音像潮，但不是海。  
母亲的蜡笔在内袋，用布包着，从来不画。

**异常 2:40–6:00**  
一块版特别旧。她磨。平面看：什么都没有。她手停。把版斜向灯管：极淡的圆，像被磨掉的星球还不肯走。版背面手指摸到刻号，未让观众读清，只有 `…01` 的凹痕。  
监督走过。她把版放平。圆消失。监督点头。过。

**触碰 6:00–9:20**  
收工。铜版入筐，推往熔炉。炉门橙光。别人已经离开。她抽出一张劳动记录的废纸（背面空白），蓝蜡笔横过来，不是画，是拓。沙沙。纸上几乎看不出。蜡笔短了一截。  
炉门关上。铜版没了。证据只剩这张纸。

**沉默 9:20–11:10**  
宿舍。同款的床。台灯。纸平放：空白。她把灯移到侧面。圆出来。移回去。圆走了。  
她不再看。把纸叠小，进胸口内袋。掌心按住。蜡笔放回布里，更短。  
眼睛：不是英雄的怒，是一种把秘密咽下去的亮。

**彩蛋** T-89-011，职务栏：印版技工。已处理。照片撕去。纸屑上有蓝粉。关联栏涂黑。

**AI-731** 「建议：清除该符号。」  
符号二字对着一张几乎空白的扫描件——系统未必扫出那个圆。观众知道它在。

### 拍摄

- 全集成片可以 **没有一帧蓝色地球**。只有蜡笔本身的蓝，和斜光里的灰痕。  
- 熔炉关门要有重量，对应第二集铁盒、第六集关站。  
- 禁止给母亲闪回面容。

## 第二集：《磁带管理员》（保留，作风格母本）

| 项 | 内容 |
|----|------|
| 档案 | T-89-058 · 数据销毁·执行人员行为评估 |
| 主角 | 男，25 岁。橙标签挂绳 |
| 核心动作 | 空壳调包，F-99 入铁盒 |
| 余味 | 他收藏了很久的「噪音」，今晚噪音开口说话 |

不改骨架。只强调三处，好让其它集跟它对齐：

1. **播放器与铁盒是旧的。** 今晚不是犯罪起点，是质变。  
2. **海浪不要配海岸画面。** 听众自己脑补海，跟第一集自己脑补圆同一机制。  
3. **B 面仍只给四碎片。** 人在想象里会自动补全句子——让他们补。

**日常** 扫码、入箱、焚毁口。橙标一排。手的摩挲。  
**异常** 「听听看。」摄像头死角。空壳换真带。系统滴一声：已销毁。  
**触碰** 关灯。A 面海。B 面四截：

1. 「如果你听到这个……」  
2. 「这盘带子是火种……」  
3. 「去听海的声音……」  
4. 「我叫……T-89-001……」

铁盒：雨、风、城市。第四盘进去。盖合。  
**沉默** 躺着。耳机摘了，海的余响还在。窗外没有海。

**AI-731** 「建议：加强对其活动的观察频率。」「频率」删改，词影「保」。

## 第三集：《回填》（新故事）

| 项 | 内容 |
|----|------|
| 档案 | T-89-091 · 资源开采·空腔处置 |
| 主角 | 男，45 岁。测声员 / 灌浆操作。粉尘、耳机压痕 |
| 核心动作 | 留下一张过曝的热敏照片，看着浆把空洞灌死 |
| 本集不给 | 遗体、臂章、可读遗言、「求救」 |
| 余味 | 下面曾经是一间「房间」；现在是地板 |

### 为什么改

挖出宇航员太像探险片，余味会被情节吃掉。第二集的力量是 **没看见海**。本集的力量是 **没看见人**。

### 因果

他的岗位：听。钻杆声波判空腔，有空腔即灌浆，日志写「地质空洞，已回填」。本周同一坐标第二次报警——十年前灌过一次（表格页脚格式从元年沿用）。今晚回波延迟太长，不像气泡，像一间有尺寸的屋子。他放下规程外的接触话筒（旧的，磁头，跟磁带是一个年代）。耳机里：金属冷却的嘀、一声极像呼吸的衰减。规程要求拍一张空腔照片。热敏打印过曝：只有一个苍白的圆，可能是头盔反光，可能是灯。他没把照片附进电子档（电子档自动生成「玄武岩纹理」）。照片进午餐铁盒。黎明，他执行自己的灌浆。浆面最后一颗气泡破掉。他看完才走。

### 分场（12'）

**冷开** 声波频谱。坐标。红字：空腔。旧档戳：移民历 7 年已回填。

**日常 0:20–2:30**  
夜班。他只面对波形，不面对井。点头、调增益、喝冷水。耳机是身体的一部分。井壁震动从靴底上来。

**异常 2:30–6:10**  
波形这次拖尾。他皱眉，把增益降下又升。不像石头。  
接触话筒。私货。线垂下去。听。  
长衰减。嘀、嘀。像屋子在自己冷却。有一下很像吸气。他拔掉话筒——太像了。  
规程平板闪：请采集视觉样本。探头下去。监视器过曝。他按打印。热敏纸吐出一张白圆。电子档已经写好「玄武岩」。他看着那行字，把热敏纸折两次。

**触碰 6:10–9:30**  
午餐铁盒打开：本应是营养块。他垫一张油纸，把白圆放进去，合盖。（铁盒形状让人想起第二集，但更瘪、更脏，不是同一只。）  
黎明。灌浆开始。他可以交给下一班。他没交。手按阀。浆下去。监视器从「深」变成「无」。地面一个口，浆面慢慢静。一颗气泡。破。平。

**沉默 9:30–11:10**  
他坐在井口边缘，摘耳机。世界忽然没有回声。铁盒在包里。他正常打卡。不回头看井——井已经没有可看的。

**彩蛋** 销毁车轮（E02 同一伤痕）。橙手套收走「地质附件袋」。袋是空的。手套停一拍。关上。  
页脚印刷体：表格模板 `T-89-001 / 元年`。

**AI-731** 「回填完成。视觉样本：缺失。」空一拍。「建议：观察操作员对空腔的停留时间。」

### 拍摄

- 绝对不要拍舱内尸体。最多过曝白圆。  
- 声波可以做成几乎好听的东西，让观众自己害怕自己的联想。  
- 灌浆过程是本集「圆被关上」：洞从黑变灰变无。

## 第四集：《底漆》（新故事）

| 项 | 内容 |
|----|------|
| 档案 | T-89-106 · 设施维护·观察窗封闭年检 |
| 主角 | 女，65 岁。密封巡检员。无袖章，手套有旧漆痂 |
| 核心动作 | 把漆从观察窗上刮开，看，再刷回去；今年多看了四分钟 |
| 本集不给 | 宇航服、气闸按钮、广场发言、氧气配额戏 |
| 余味 | 这扇窗是她自己在元年涂上的 |

### 为什么改

穿上宇航服走向大门，是「出发」。第二、六集都不是出发，是 **留下**。  
本集她的职业就是把能看的地方漆死。她每年打开一次自己当年的作品，看一眼，再封上。像第六集每天写无异常。第十七年，她看久了一点。只多一点。

### 因果

近地侧一条废廊有一扇直径三十厘米的观察窗，元年按令刷成「结构加固」。她当年是刷漆的人之一。现岗位：年检密封。日历只圈这一天。她刮开、目检玻璃、重刷，写「封闭良好」。本周光学清退，条例仍要她来。刮开后，玻璃后是一条真天空的缝——本集地球只以 **过小、过短、被窗框切碎** 的方式存在，看不清，足够让人想。她多看了四分钟。重刷。湿漆里映出她的脸。闪回不必语言：元年，一双年轻的手把漆桶递给她，出焦，袖口一闪。她刷上第一道。窗黑了。

### 分场（12'）

**冷开** 年检单。项目：观察窗封闭。周期：年。执行人栏她的名字写过很多遍，旧复写纸印到下一页。

**日常 0:20–2:40**  
家。撕日历。红圈。漆刷浸泡。手套。纸堆到踝——十七年的年检黄票。  
走廊。灯坏了两盏。窗在尽头，黑圆，像墙长了瞳孔然后被烫瞎。

**异常 2:40–6:00**  
刮。漆屑。很厚。她的动作熟到残忍。露出玻璃。外面：黑，和一点不像灯的光。她把脸靠近。我们只给她眼睛的反光，不给可识别的行星全貌。呼吸在玻璃上起雾。她用手抹开。又起雾。

**触碰 6:00–9:40**  
她没有掏通讯器。机械表在走。年检时限本够用。她看。表针走过该重刷的点。再看。四分钟。  
然后她打开底漆。刷。第一道。圆在消失。第二道。黑。她看着湿漆，自己的脸在上面，老。

**沉默 9:40–11:10**  
黄票：「封闭良好。」签字。原路返回。手套不洗。家里日历已撕，明天是空白。她把刷子泡上，像泡了十七年。

**彩蛋** 同机位叠化。元年。年轻的她。出焦的人把漆桶放下，手按了按她的手腕，不是抓按钮，是按「开始刷」。一句气声，可听可不听：「还不是时候。」第一道漆。窗黑。时间码 +17 年，回到她苍老的侧脸。

**AI-731** 「样本完成例行封闭。观察时长超出阈值 4:12。仅观察。」

### 拍摄

- 窗只有 30cm，构图永远被切。这是「浮想联翩」的物理条件。  
- 元年与现在必须可叠化：同一颗螺丝、同一道刷痕方向。  
- 不要广场，不要别人。这集只有她、窗、漆。

## 第五集：《第187次》（新故事，骨架更瘦）

| 项 | 内容 |
|----|------|
| 档案 | T-89-118 · 公共运输·末班车黑匣子 |
| 主角 | 男，45 岁。末班司机 |
| 核心动作 | 因窗膜起皮而看了；误过站；第二圈是故意的；不复位 |
| 本集不给 | 隧道刻字、新刻「我看见了」、停车读标语 |
| 余味 | 多出来的两圈可能只是手的事故，也可能不是 |

### 为什么改

标语会把想象钉死。「蓝的是真的」是答案。第二集从不给答案。  
本集只留：重复、起皮、数。观众自己决定他算不算醒了。

### 因果

地面段驾驶窗有防认知污染膜，地球在膜后是灰石。187 次他都偏头，因为灰石也烦。本周膜老化，裂开一条。蓝从裂缝里走出来——仍是那套地球资产，只露出一条。他没偏头。于是没在该刹车的节拍刹车，过站。要补这一站，必须再绕。绕的时候他没有把膜按回去。第二圈，他的手可以按，没按。计数 189。交班，复位键，不按。一条撕下的膜粘在手套上，他没揭。

### 分场（12'）

**冷开** 黑匣子。今日计划：187。窗膜型号、更换逾期。

**日常 0:20–2:20**  
灯。轨。他的脖子在地面段到来时自动偏 15 度。一次即可让观众读懂习惯。灰石在膜后一晃。

**异常 2:20–5:40**  
第 187。膜裂。一条蓝，云，极短。他没偏。轨道节拍还在。该减速的点过去了。车空。下一站的灯在身后。他的手后知后觉。

**触碰 5:40–9:20**  
他可以报故障停车。没报。再绕一圈。膜的裂口还在。这一次他的眼睛等着那条蓝。来。走。隧道黑。  
再一圈。第三次地面段。他看。计数 189。  
全程无配乐。只有轨缝。

**沉默 9:20–11:10**  
「今晚无异常。」复位键。停。不按。手套上一条卷曲的膜，反面蓝一点，正面灰。值班员在看天幕，没看他。  
车库役用缝。他站了一会儿。头没抬满——也可以理解为他不敢。切黑。

**彩蛋** 黑匣子波形：两段多出来的「静」，静里其实有风声。档案员界面把它们标成可裁切。光标停在「裁切」上，不点。操作者不出画。

**AI-731** 「班次记录：187→189。窗膜更换：未申报。」下一行多一个句号，像写完又想写。

### 拍摄

- 蓝只存在于裂口宽度，像第一集的斜光、第四集的切框。  
- 不要英雄特写看向远方。可以拍手套、计数器、偏了十七年的那条颈筋第一次没动。

## 第六集：《17年》（保留，作风格母本）

| 项 | 内容 |
|----|------|
| 档案 | T-89-143 · 关停设施·留守人员观察 |
| 主角 | 男，70 岁 |
| 核心动作 | 写下「今日有异常：地球还在」，折入口袋，不贴墙 |
| 余味 | 目镜还在看，人已经走了 |

不改骨架。对齐其它集的三处：

1. **近地侧隔离带**，不是月背。  
2. **17 年透过镀膜看灰石**，所以他一直可以写无异常；磨穿的当天对上广播「已死亡」。  
3. **最后一帧是没人的目镜**，把「看」还给空房间——与第二集「耳机摘了海还在」同构：介质比人耐久。

墙上年纸、角落实日历纸（与第四集同款，不点破）。脊道安全索。远穹顶。安检「欢迎回家」。广场天幕假圆。他抬头，不说话。

**AI-731** 「样本已脱离岗位。后续安置：普通居民区。」细字：「17年。足够了。」

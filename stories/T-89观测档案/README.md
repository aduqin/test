# 《T-89观测档案》第一季

## 设定一句话

在月球殖民地上，官方宣称地球已死；六个普通人各自用一个微小动作，证明自己看见了蓝色。

## 全季核心设计原则

| 原则 | 说明 |
|------|------|
| 单集独立 | 每集可单独观看，不依赖其他集理解 |
| 动作微小 | 没有一个主角做出「大动作」，全是普通人能做到的事 |
| 台词极简 | 六集台词总量不超过 10 句 |
| 沉默叙事 | 关键情感瞬间不加音乐、不加旁白 |
| 混合叙事 | 70% 正常拍摄 + 30% 档案素材 |
| 时间视觉化 | 用磨损、泛黄、涂层消失等物理细节表现时间 |
| 开放结局 | 没有一集解决任何问题，每集都在积累问题 |

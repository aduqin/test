# 《T-89观测档案》

科幻短篇系列剧创作档案库。

## 系列简介

月球殖民体制下，普通人如何用极小的动作质疑官方叙事。每集独立成篇，以「观测档案」形式串联；真正的主角是从未正面出现的幽灵 **T-89-001**，以及逐渐失效的审查系统 **AI-731**。
